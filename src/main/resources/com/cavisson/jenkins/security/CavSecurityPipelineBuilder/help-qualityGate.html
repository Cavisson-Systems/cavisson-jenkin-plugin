Optional. Name of the quality gate to evaluate after the scan finishes — sent as qualityGateName in the evaluate request. When set, the quality-gate evaluation REST call is triggered after Static, Container (SCA), or Dynamic (DAST) scans (for Static, only if the scan also produced a SonarQube ceTaskId); when left empty, quality-gate evaluation is skipped. Typically set via Pipeline (qualityGate: 'Release Gate').
